Open Source · Python 3.9+ 零依賴 · macOS + iPhone ➔ Pixel 4

📸 Pixel 4 無限 Google 相簿中繼系統

將 iPhone 手機與 Mac 電腦的照片／影片自動分批中繼到 Pixel 4（或 Pixel 1–5）， 透過 ADB 雙緩衝暫存與 UIAutomator 自動備份偵測，安全無痛享受 Google 相簿不計容量的無限空間備份。

⭐ 前往 GitHub 專案下載 ⚙️ 線上產生 config.json 設定檔

🔄 系統運作流程（安全不爆空間設計）

1. iPhone & Mac 集中 iPhone 透過 iCloud 同步、AirDrop、PhotoSync 或 USB 匯入 Mac 指定資料夾，與 Mac 本機照片一起納入掃描範圍。
2. 彈性範圍與帳號去重 依設定的 Google 帳號標籤、日期區間、檔案類型過濾，並由 SQLite 紀錄已同步檔案，切換帳號也不混淆。
3. ADB 雙緩衝預載 先將安全批次容量（預設 15 GB）推送至 PixelStaging/.nomedia，避免 Google 相簿讀取到傳輸一半的檔案。
4. 自動偵測備份並清空 移入 DCIM/Camera 觸發無限上傳；偵測 Google 相簿顯示「備份完成」後自動清空 Pixel 空間，接力下一批。

⚙️ 線上互動式設定產生器（保留帳號與檔案範圍彈性）

填入你自己的帳號標籤、Mac / iPhone 來源路徑與篩選條件，即可直接下載專屬 config.json（所有設定僅在你的瀏覽器本地產生，不會上傳任何資料）。 


    


    

      
🚀 在 Mac 上 30 秒啟動本機控制台

      
git clone https://github.com/zhijaysun0915/pixel4-gphotos-relay.git
cd pixel4-gphotos-relay
# 將上方下載的 config.json 放入此資料夾（或啟動後直接在網頁修改）
python3 app.py

      

        執行後會自動開啟 http://localhost:8765 本機控制台，即可查看 Pixel 4 連線、掃描預覽並一鍵開始備份。
